# SimpleProxyChat Testing Servers

Yes... I used AI to generate the scripts to run them all at once. Bite me.

## Setup

You need to download, and place the jars in the appropriate places.

### Velocity

| Type       | Download URL                                      | Path                | Name       |
|------------|---------------------------------------------------|---------------------|------------|
| Velocity   | [Download](https://papermc.io/software/velocity/) | Velocity/1 - Proxy  | proxy.jar  |
| Paper      | [Download](https://papermc.io/downloads/paper)    | Velocity/2 - Paper  | server.jar |
| Fabric     | [Download](https://fabricmc.net/use/server/)      | Velocity/3 - Fabric | server.jar |

### Bungeecord

| Type       | Download URL                                                 | Path                  | Name       |
|------------|--------------------------------------------------------------|-----------------------|------------|
| Bungeecord | [Download](https://hub.spigotmc.org/jenkins/job/BungeeCord/) | Bungeecord/1 - Proxy  | proxy.jar  |
| Paper      | [Download](https://papermc.io/downloads/paper)               | Bungeecord/2 - Paper  | server.jar |
| Spigot     | [Download](https://www.spigotmc.org/wiki/buildtools/)        | Bungeecord/1 - Spigot | server.jar |

## Starting the Servers

On Windows, simply run `start-all.bat`. It's pretty self-explanatory.

> Note: You can also just run the servers individually.
